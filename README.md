# Fresh Beatz 🎹

**EN** · [DE](#deutsch)

A pocket chord synthesizer and looper as a PWA, inspired by the HiChord Pocket concept. Pure HTML/CSS/JS with the Web Audio API, no dependencies, no build step, no ads. Works offline once installed. Not affiliated with HiChord; no logos or branding of the original are used.

## Features

- **4 chord pads** (I IV V vi) in any key, major or minor, plus **Alt** for ii iii vii I′
- **Modifiers:** 7th, Sus, Alt. Quick tap = latch, hold = momentary
- **6 sounds:** Pad, Keys, Pluck, Organ, Glass, Chip, with tone (filter) and reverb
- **Arpeggiator:** up, down, up/down, random at 1/4, 1/8, 1/16
- **Looper:** 1/2/4/8 bars, count-in, metronome, quantize, overdub layers, undo layer, clear
- **Joystick** (spring-loaded): left/right = pitch bend ±2 semitones, up/down = octave for newly played chords. Works with multitouch while you play
- **Drum mode** (🎹/🥁 button): Kick, Snare, Hat, Open hat, Tom, Clap, Crash on the pads (synthesised, recordable into the loop), plus **auto beats** (Rock, Hip-Hop, House, Lo-Fi) in the clock menu
- **Audio export:** record the master output and download it (webm/ogg, m4a on iOS)
- **Multitouch**, tap tempo (loudness is up to the system volume)
- **Dark mode** (follows the system, switchable), **English / Deutsch**
- **Landscape and portrait** layouts, installable, offline-capable

## Controls

| Control | What it does |
|---|---|
| 4 big pads | Play chords (hold = sustain) |
| 7th / Sus / Alt | Modifiers |
| Key button (grey) | Key and major/minor |
| Wave button (yellow) | Sound, tone, reverb |
| Clock button (red) | BPM, tap tempo, arpeggio, auto beat, loop length, metronome, quantize, count-in |
| Display (tap) | Settings: language, theme, audio export, install |
| ● | Record into the loop (count-in first if nothing is running) |
| ▶ / ■ | Start / stop loop |
| ↶ / ✕ | Undo last layer / clear loop |
| Joystick | Pitch bend (left/right) and octave (up/down), springs back |
| 🎹 / 🥁 | Switch between chord pads and drum pads |

Desktop keys: `A S D F` chords · `Z X C` modifiers · `Space` play · `R` record · `M` chords/drums.

## Run locally

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

(Service workers and install need `localhost` or HTTPS.)

## Deploy on GitHub Pages

1. Put all files in the repository root (or a `/docs` folder).
2. *Settings → Pages →* choose the branch and folder.
3. Open the Pages URL on your phone and add it to the home screen.
   - Android/Chrome: menu → *Install app*
   - iPhone/iPad: Share → *Add to Home Screen*

All paths are relative, so it also works under `https://user.github.io/repo/`.
After changing files, bump `CACHE` in `sw.js` (e.g. `fresh-beatz-v3`) so installed apps pick up the update.

If the browser doesn't offer *Install*: open DevTools → *Application → Manifest*. It lists what is missing. All files including `icons/` and `sw.js` must be deployed, and the page must be served over HTTPS (GitHub Pages is).

## Latency notes

- Audio runs with `latencyHint: 'interactive'`; notes start on `pointerdown` (no click delay).
- Typical: ~20–60 ms on Android, ~10–30 ms on iOS. **Bluetooth headphones add 100–250 ms**, so use wired or the speaker for playing.
- Loop and arpeggio timing uses Web Audio's clock with lookahead scheduling, so it stays tight regardless of UI load.
- Voice count is capped to keep low-end phones glitch-free.

## iOS notes

- Audio starts after the first touch (Safari rule).
- iOS 17+: the mute switch is bypassed via `navigator.audioSession`. Older versions use a silent-audio workaround.
- No vibration or Web MIDI on iOS Safari.

### Latenz

- Audio läuft mit `latencyHint: 'interactive'`, Töne starten direkt bei `pointerdown`.
- Typisch: ca. 20–60 ms auf Android, 10–30 ms auf iOS. **Bluetooth-Kopfhörer addieren 100–250 ms**, zum Spielen daher Kabel oder Lautsprecher nutzen.
- Loop und Arpeggio laufen auf der Web-Audio-Uhr mit Vorausplanung und bleiben dadurch auch bei UI-Last im Takt.
- Die Stimmenzahl ist begrenzt, damit schwächere Handys nicht knacken.

### Hinweise iOS

- Audio startet erst nach der ersten Berührung (Safari-Regel).
- iOS 17+: Der Stumm-Schalter wird über `navigator.audioSession` umgangen, ältere Versionen nutzen einen Silent-Audio-Trick.
- Keine Vibration und kein Web MIDI in iOS-Safari.
